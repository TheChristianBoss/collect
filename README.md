# Collect

A collection of four video-editing application source trees, supplied as ZIP archives and organized in separate directories.

| Folder | Project |
| --- | --- |
| `kdenlive/` | Kdenlive |
| `lossless-cut/` | LosslessCut |
| `openshot-qt/` | OpenShot Qt |
| `shotcut/` | Shotcut |

Each folder retains the contents of the corresponding supplied source ZIP (with its original top-level archive folder removed). Individual upstream licenses and notices are preserved in their respective folders. See `SOURCE_ARCHIVES.md` for archive checksums and file counts.

**Note:** These are independent applications, not a single combined build. Changes to each project should be made in its own directory.
